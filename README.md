# Fretline

A guitar practice room that runs in the browser and installs as an app.

- **Chord changes:** a metronome trainer and one-minute change tests; the microphone counts your changes.
- **Strum coach:** play along with a backing track or the real recording, and the microphone times every strum against the pattern. It finds the beat, the chords and the sections of a song you load, so you can loop one part.
- **Rhythm ladder:** fourteen strumming patterns in teaching order, including keherwa and dadra grooves on a synthesized dholak.
- **Lead player:** riffs in tab, played back as you read them, and a Follow mode that waits for you to play each note.
- **Practice time:** counted from what you actually play, not a timer.

Everything runs locally in the browser with the Web Audio API: no server, no account. Progress is kept on the device; use Progress → Setup → Export / Import to move it.

Live: https://sahilsethi16.github.io/fretline/
